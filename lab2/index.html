Базові елементи інтерфейсу користувача (UI Elements)

Огляд 10 ключових компонентів веб-інтерфейсу, їх призначення, особливості та інтерактивні приклади використання.

Швидкий перехід:
1. Radiobutton 2. Checkbox 3. Text input 4. Tabs 5. Button 6. Text label 7. Link 8. Tooltip 9. Dropdown list 10. Data grid
01

Radiobutton (Радіокнопка / Перемикач)

Призначення:

Радіокнопка дозволяє користувачеві вибрати рівно один варіант із набору взаємовиключних опцій. Коли вибирається одна радіокнопка, будь-яка інша кнопка в тій самій групі автоматично стає невибраною.

  • Коли використовувати: коли є від 2 до 5-7 взаємовиключних варіантів (наприклад: вибір статі, способу доставки, платіжної системи).
  • Особливість: усі радіокнопки в одній логічній групі повинні мати однаковий атрибут name.

02

Checkbox (Прапорець)

Призначення:

Прапорець призначений для вибору одного, декількох або жодного значення зі списку незалежних опцій, а також для перемикання бінарного стану (увімкнено / вимкнено, так / ні).

  • Коли використовувати: для множинного вибору (фільтри товарів, теги) або підтвердження згоди з правилами.
  • Особливість: на відміну від радіокнопок, вибір одного чекбоксу жодним чином не впливає на стан інших.

03

Text input (Текстове поле введення)

Призначення:

Однорядкове поле введення, яке дозволяє користувачеві ввести довільний або структурований текст за допомогою клавіатури.

  • Коли використовувати: введення імені, логіна, адреси електронної пошти, пароля, номера телефону, пошукових запитів.
  • Особливість: атрибут type (наприклад: text, email, password) визначає тип даних, а placeholder слугує короткою текстовою підказкою.

04

Tabs (Вкладки)

Призначення:

Вкладки слугують для компактної організації та структурування вмісту на сторінці. Вони дозволяють перемикатися між різними розділами або категоріями інформації в межах однієї площини без перезавантаження сторінки.

  • Коли використовувати: картки товарів (Опис / Характеристики / Відгуки), панелі налаштувань, перегляд коду/результату.
  • Особливість: лише один блок вмісту активний і видимий одночасно, інші тимчасово приховуються.

05

Button (Кнопка)

Призначення:

Кнопка — це базовий інтерактивний елемент керування, який ініціює негайну дію при натисканні (відправка форми, відкриття діалогового вікна, збереження змін, скидання даних тощо).

  • Коли використовувати: для виклику будь-якої активної дії на веб-сторінці.
  • Особливість: за стилем кнопки зазвичай поділяють на Primary (основна дія), Secondary (другорядна) та Danger (деструктивна дія), а також передбачають візуальні стани hover, active та disabled.

06

Text label (Текстова мітка)

Призначення:

Елемент <label> представляє пояснювальний підпис або назву для елемента інтерфейсу (поля введення, чекбоксу, радіокнопки чи списку).

  • Коли використовувати: завжди поруч з кожним елементом введення для зрозумілості та доступності (accessibility).
  • Особливість: зв'язується з інпутом через атрибут for="id_елемента". При кліку на мітку фокус автоматично переходить на відповідне поле введення, що суттєво полегшує взаємодію на мобільних пристроях.
Приклад:

Клік по назві поля активує інпут завдяки атрибуту for="interactive-label-input".

07

Link (Гіперпосилання)

Призначення:

Гіперпосилання (тег <a>) слугує для навігації між сторінками вебсайту, переходу на зовнішні ресурси, завантаження файлів або переміщення до конкретних розділів (якорів) поточної сторінки.

  • Коли використовувати: коли дія веде до зміни URL, переходу на інший екран або зовнішній ресурс (на відміну від кнопки, яка виконує дію на місці).
  • Особливість: основний атрибут — href. Для зовнішніх посилань рекомендовано додавати target="_blank" rel="noopener noreferrer".

08

Tooltip (Спливаюча підказка)

Призначення:

Спливаюча підказка відображає коротку допоміжну або контекстну інформацію, коли користувач наводить курсор миші (hover) або переводить клавіатурний фокус на відповідний елемент.

  • Коли використовувати: для пояснення іконок без тексту, складних термінів, правил заповнення пароля чи скорочень.
  • Особливість: не перевантажує основний простір сторінки і з'являється лише за потреби користувача.

09

Dropdown list (Випадаючий список / Select)

Призначення:

Випадаючий список (тег <select>) дозволяє користувачеві обрати один варіант із компактного переліку, який у згорнутому стані займає лише один рядок.

  • Коли використовувати: коли кількість варіантів більше 5-7 (наприклад: вибір країни, міста, місяця народження, мови інтерфейсу), коли радіокнопки зайняли б занадто багато місця.
  • Особливість: кожен варіант задається тегом <option>, а атрибут selected задає варіант за замовчуванням.

10

Data grid (Таблиця / Таблиця даних)

Призначення:

Таблиця даних слугує для структурованого відображення великих обсягів однотипної інформації у вигляді рядків та стовпців для зручного візуального порівняння, аналізу та сприйняття.

  • Коли використовувати: для перегляду списків замовлень, баз користувачів, прайс-листів, розкладів занять, фінансових звітів.
  • Особливість: містить заголовки (<th>), рядки даних (<tr>, <td>), використовує підсвічування парних рядків («зебра») та ефект наведення для зручності читання.
